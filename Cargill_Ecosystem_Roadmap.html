DugoutOS — How It Works

DugoutOS is not a side project. It is one of four pillars in the ecosystem. Bananas 2K15 runs on it, proving the product works in a real org. The product gets licensed, funding the nonprofit. Coaches coach better. Families pay less. Every piece is connected.

What it does
Practice Planning
AI-generated plans from roster + stats + season phase. Drill library. Station assignments. Coaches approve or edit.
Player Development Tracking
Per-player dashboards. Coach notes. GameChanger stat import. AI development summaries. Parent-facing progress view.
Tournament Operations
Bracket tracking, hotel info, exportable itinerary PDF and .ics calendar. Families get one link with everything.
Parent Communications
BAND post generator, practice reminders, game day announcements. AI drafts. Coaches approve. One channel.
NCS Roster Intelligence
Python + GitHub Actions scraper monitors competitor 12U Central Texas rosters. Alerts when a player's status changes — your tryout pipeline in real time.

How it holds together

Five Pillars

01
Separate Every Function
Co-Directors run org. Coaches coach. Board governs. Each entity has a lane. Nobody's phone has everything running through it. This is what prevents burnout and builds trust.
02
Family First — Always
Written into bylaws. Applies to coaches, staff, and org decisions. A coach who shows up for their daughter's game is modeling the exact values we put on the field every practice.
03
Full Financial Transparency
Every dollar published. Quarterly reports to board and donors. Allocation model board-voted annually. The org earns trust by showing the math — not asking families to take it on faith.
04
Build the Runway First
No debt. No loans. Phase 1 deposits fund Phase 2. Phase 2 closes Phase 3. Grants extend the runway. The sequence exists so the org never operates from desperation.
05
The Tech Funds the Mission
DugoutOS generates SaaS revenue that flows to NAI. Next-Gen IT funds the Cargill household which seeds NAI. The org runs on the platform, which proves the product, which gets licensed. It's a flywheel — every piece accelerates every other piece.
